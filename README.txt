TAKASH WHATSAPP - V1 PROTOTYPE

This is a mobile-friendly prototype. It runs in a browser and does not yet have a real online database.

On Android:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use your browser's "Add to Home screen" option to make it feel like an app.

Next development stage:
